# pva-1k-ukol3

Create an app which takes in a string with encoded emoji (like `:joy:`) and prints out the same text but with the encoded emoji replaced by an actual emoji character.

Requirements:
1. Use venv to create a virtual environment for the project
2. Use a main guard (`if __name__ ==  "__main__"`)
3. Use a local import (split the project into at least two modules)
